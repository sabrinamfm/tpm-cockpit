  Template Error Analysis

  Root cause: The errors are false positives — VS Code's HTML/CSS linter chokes on Jinja2 delimiters ({%, {{, %}) inside inline style="" attributes. The templates are valid and render correctly at runtime.

  Cleanest fix (Option A — move to stylesheet, 5 min):

  In base.html, the existing .display-id rule (line 87) already sets font, color, and margin. The only override in program_detail.html:19 is font-size:13px;. Extract that:

  1. Add .display-id--lg { font-size: 13px; } to the stylesheet block in base.html.
  2. Replace style="font-size:13px;" on the <span> with class="display-id display-id--lg".

  This eliminates the linter noise, no suppressions needed, and keeps styling in one place.
