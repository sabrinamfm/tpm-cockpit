# Phase 1 — Local TPM Workspace

## Goal

Build a local-first TPM Cockpit that helps a TPM manage programs, work items, risks, dependencies, decisions, stakeholders, notes, and basic reporting inputs.

Phase 1 is not about automation or advanced intelligence. It is about creating a usable operational workspace.

## Scope

Phase 1 includes:

- Create and manage programs (implemented, needs improvement)
- Create and manage work items (implemented, needs improvement)
- Track risks
- Track dependencies
- Track decisions
- Track stakeholders
- Add notes to programs
- Preserve data locally (partially implemented, only programs and work items)
- Prepare the foundation for future reports

## Out of Scope

Phase 1 does not include:

- Jira integration
- Slack integration
- AI-generated reports
- Multi-user collaboration
- Cloud deployment
- Authentication
- Advanced analytics

## Success Criteria

Phase 1 is successful when a TPM can:

- Create a program
- Add operational context
- Track work items
- See what needs attention
- Preserve data safely across app updates
- Use the app locally without cloud infrastructure
